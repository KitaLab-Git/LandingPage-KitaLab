# Sprint 2 — Core Landing Page

Sprint 2 mematangkan empat section utama landing page Kita Lab agar siap
ditampilkan kepada calon pelanggan.

## Cakupan selesai

- Navbar sticky dengan enam tautan utama, CTA konsultasi, dan menu mobile.
- Hero dengan headline, subheadline, dua CTA, serta tiga poin kepercayaan.
- Section Tentang Kita Lab dengan positioning, nilai kerja, dan alur kolaborasi.
- Section Layanan dengan tiga kategori, deliverable, dan CTA konsultasi.

## Verifikasi

- Navigasi anchor tersedia untuk Home, Layanan, Product, Portofolio,
  Tentang Kami, dan Kontak.
- Layout responsif untuk mobile, tablet, dan desktop.
- `pnpm lint` dan `pnpm build` wajib lulus sebelum perubahan dipublikasikan.
